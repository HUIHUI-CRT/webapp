## 3. 静态文件挂载

- 挂载点 `"/"`（name=`frontend`）：把 `frontend/` 目录整体对外提供，
  例如 `GET /index.html` → `frontend/index.html`、`GET /js/common.js` → `frontend/js/common.js`。
  它注册在所有 API 路由之后，未命中 `/api` 的请求才会落到这里。

前缀匹配清单（同一台服务器、同一个端口）：

| 路径前缀 | 归属 | 处理文件 |
|---|---|---|
| `/api/posts*` | 博客 | `backend/app/routers/blog.py` |
| `/api/files*`、`/api/upload`、`/api/download/*` | 文件 | `backend/app/routers/files.py` |
| `/api/tasks*`、`/api/polls*`、`/api/activity`、`/api/stats`、`/api/search` | 小组协作 | `backend/app/routers/workspace.py` |
| `/api/health`、`/api/ext*`、`/api/rooms` | 运维 | `backend/app/main.py` |
| `/ws` | 聊天 + 画布 | `backend/app/routers/ws.py` |
| `/docs`、`/openapi.json`、`/redoc` | FastAPI 自动文档 | 框架内置 |
| 其余全部 | 前端静态页面 | `frontend/` |
